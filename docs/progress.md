当前根目录 `AlienShooter.sln` 只包含一个主程序项目，配套 `.vcxproj`、`.filters`、`.user` 均在同级，依赖位于 `src/3rdparty/`。入口为 `build.bat`，exe 位于 `bin/Debug/`、`bin/Release/`。阶段一至十六保留历史记录，旧 CMake、脚本和多项目路径不再作为当前用法；最新素材流水线状态见阶段十七。

## 阶段一：调研与方案

已确认嵌套目录 alien_shooter_java_re 才是 Git 工程，工作开始时无未提交修改。原版 e.java 共约 4910 行，d.java 提供菜单和文字绘制，c.java 提供 MIDI 播放控制。正式素材包括八关、85 个组合帧、155 个部件和 17 个 MIDI。

可用环境：Visual Studio Community 2026 / MSVC，CMake 4.3.1，已有项目 .venv 和已确认音色依赖。当前没有 C++ 运行时代码。

方案见 implementation-plan.md。下一阶段建立可编译工程与独立资源/MIDI/世界模块，再按原版行为逐项接入。
