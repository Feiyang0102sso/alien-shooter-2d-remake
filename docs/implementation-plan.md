# 游戏重建实施方案

日期：2026-10-04。工作窗口：用户授权约八小时自主推进。

## 方案及审核依据

用户已明确开始编码，指定 C++17、Visual Studio solution、MIDI、原版 UI/玩法及桌面按键，并授权自行解决问题。本方案按该授权执行，不再次等待用户醒来审批。先核实原版方法再实现对应模块；没有证据的细节列为待验证，不自行添加玩法。

1. 固定 raylib 5.5、nlohmann/json 3.12.0，直接维护原生 MSVC solution / vcxproj，仅保留 build.bat 构建入口。
2. 正式运行时只加载 assets。保留 240×320、最近邻整数缩放、原菜单底图及原绿色位图字库。
3. 按 e.java 的 80ms 离散逻辑更新重建横版物理、组合角色、五种武器（默认手枪及四种可拾取枪械）、八关对象、机关及通关条件。渲染与逻辑解耦。
4. MIDI 使用原 SMF 事件及 tempo map；音色沿用用户已确认的 FluidSynth 2.6.1 / GeneralUser GS 2.0.3。采样计数调度，不以 OGG 的释放尾音决定事件长度。保留 c.java 单活动播放器、打断、续播及结束后重播语义。
5. 核心世界逻辑与渲染分离，使用原关卡进行自动验证；图形运行输出真实截图，逐项复核菜单、角色、地图与 HUD。

## 输入映射

| 桌面输入 | 原版动作 |
| --- | --- |
| A / D | 左 / 右移动 |
| W | 跳跃；蹲姿时先站起 |
| S | 蹲姿 / 向下查看 / 终端交互 |
| 鼠标左键 | 朝角色面向方向攻击 |
| 1–4 | 机枪、喷火器、火箭筒、爆能枪（须已拾取） |
| 5 | 默认手枪 |
| Q / E | 循环选择已取得武器 |
| Esc | 暂停 / 返回 |

原版只向左右射击；鼠标位置不引入自由角度瞄准。原版不允许空中开火，攻击期间锁定横向移动；复核确认站姿攻击可按 W 取消并起跳，按此规则实现。

## 核实边界

- 原包和反编译源码是当前主要依据，尚无原机录像。不能把“能运行”写成逐像素或逐帧 1:1 验收。
- 原源代码中的护甲公式和英文帮助描述存在冲突：轻甲实际负伤乘 5 后算术右移 4 位，源码优先，差异另记。
- assets 是生成产物，不直接修改已有自动管理文件；新增运行时音色库和依赖应有明确来源及许可。
- 不删除用户已有注释；工具流水线保留其历史 OGG 能力，游戏的新音频路径直接使用 MIDI。
