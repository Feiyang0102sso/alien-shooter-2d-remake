# Alien Shooter 桌面重建版

基于 NET Lizard 的 Java ME 版，使用原关卡、图片、位图字库和 MIDI。支持 Windows 10/11 x64，当前版本见 `AlienShooter.exe` 的文件属性。

## 启动

双击同目录的 `AlienShooter.exe`。请保留旁边的 `assets/` 和 DLL；不要只复制一个 exe。默认系统已安装 x64 MSVC 运行库，游戏目录不附带该运行库。无需安装 Python、Java 或 Visual Studio。

开场后出现声音询问，按 **Y / Enter** 开启，按 **N / Esc** 关闭，也可点击左右下角 YES / NO。在菜单中用 W/S 或方向键选择，Enter 确认；鼠标左键也可点击菜单项。

## 操作

| 输入 | 动作 |
| --- | --- |
| A / D | 左右移动 |
| W | 跳跃；蹲下时先站起，再按一次跳跃 |
| S | 停稳后蹲下；继续按住向下看；站在已启用终端前进入终端 |
| 鼠标左键 | 按角色面向开火，按住连续攻击 |
| 1 / 2 / 3 / 4 | 机枪 / 喷火器 / 火箭筒 / 爆能枪，需要先拾取 |
| 5 | 默认手枪，弹药无限 |
| Q / E | 前后切换已取得武器 |
| Esc | 暂停、返回；主菜单中退出 |

鼠标位置不改变射击方向。原版攻击期间锁定横向移动，站姿射击可以按 W 取消并起跳，空中不能开火；停稳后再蹲。蹲姿射击时需等攻击结束才能站起。低矮敌人贴近时，默认手枪通常需要蹲射。武器用尽会自动切换。

帮助/关于页支持 W/S、方向键、鼠标滚轮和 Page Up / Page Down。失去窗口焦点时自动暂停。窗口按 240×320 原画布整数倍缩放，可拖动窗口边缘改变大小。

## CHGOD 秘籍

游戏中连续输入 `chgod` 开启无敌、全部武器及满弹药，不区分大小写；弹药正常消耗。再次输入关闭，恢复开启前的武器、弹药和选枪，并中断当前攻击。暂停或失焦时不识别。重开、返回主菜单或确认过关时自动关闭，秘籍装备不会进入正常存档。

## 关卡与进度

触碰开关可恢复供电和启用对应编号终端。在生成器处持有炸药会自动放置，倒计时开始后及时撤离。部分墙和障碍可以打碎；升降台、箱子和跳跃用于穿过原版路线。消灭全部敌人及生成器后，前往 EXIT。

新游戏从第一关开始。完成一关并确认提示后，保存下一关起点；第一关尚未完成时 CONTINUE 不可用，这是原版规则。继续游戏加载最高已解锁关，重玩旧关使用该关默认装备。重开或死亡重试会恢复本关起点，不是中途即时存档。

## 存档与日志

- 存档：`%LOCALAPPDATA%\AlienShooterRemake\progress.json`
- 上一份有效备份：同目录 `progress.bak`
- 当前运行日志：同目录 `logs\latest.log`
- 损坏主存档：首次恢复时保留为 `progress.corrupt.json`

声音设备不可用时仍可静音运行，原因记录在日志。若程序启动失败，查看错误对话框给出的目录。没有声音时，先在设置中检查 SOUND ON，再检查日志中的 `MIDI ready` 或 `Audio disabled`。

## 还原范围

游戏包含八关、五类敌人、五种武器、原版机关、难度、暂停与进度流程。MIDI 用采样计数调度，保留原版打断/续播行为；音色采用前期确认的 GeneralUser GS，无法代表所有原手机音色。

目前有原字节码状态对照、5362 张画面逐像素对照、17 首 MIDI 验证及前两关独立正常输入通关回放。尚未真人完整通关全部八关；具体机制、界面和原机表现的核实边界见源码仓库验证文档。
