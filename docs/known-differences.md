# 还原边界与有意适配

## 桌面适配

- 用户指定新增 CHGOD 秘籍：无敌、全部武器、满弹药，可再次输入关闭；默认关闭，不改变未启用时的原版规则。

- 原俄文文本按前期确定方案译为英文，使用原绿色位图字形。帮助中的数字键说明替换为 WASD、鼠标和 Q/E；排版仍沿用原图文布局。
- 保留 240×320 原画布，桌面用最近邻整数倍放大，窗口外区域为黑色；窗口刷新与 80ms 游戏逻辑分离。
- 无手机振动硬件，菜单保留 VIBRATION OFF 禁用项。桌面增加失焦暂停、鼠标菜单点击和滚轮翻页。
- JSON 文件替代 Java ME RMS，存档规则保留关卡起点和最高进度，另加有效备份和错误日志。
- 音频采用已确认的 FluidSynth / GeneralUser GS。原游戏依赖手机 MMAPI，没有提供原设备音色库；MIDI 事件和打断语义可核对，无法声称合成音色与任意原手机一致。

## 保留的原版细节

- 角色只向左右开火，空中不能射击，攻击期间锁定横向移动；站姿射击可按 W 取消并起跳，蹲姿射击必须先结束才能站起。S 在终端前优先交互。
- 武器 0 是默认手枪，弹药无限。素材准备阶段 `unarmed` 标签误称徒手，暂保留资源名称兼容；运行时帮助和文档已纠正。
- 难度在载入初始敌人之后才更新共享参数：新进程第一次载入的初始敌人使用基础血量，后续生成和再次载入使用新难度。该原版顺序已通过字节码验证。
- 轻甲实际伤害算法与译文“减少一半”不一致，代码保留原整数算法；不按帮助文字反向改平衡。
- 只保留一个活动 MIDI 播放器。新声音打断旧声音、再次请求可能续播，听感可能不同于现代游戏的并行音效，这是已核实的原调用行为。
- 第一关过关前不能 CONTINUE；完成关卡并确认后保存下一关起点。
- 敌人的碰撞高度按类型共享，由可见角色按原重绘顺序回写；不会给每个实例另造一份高度规则。
- 跌落伤害使用当步重力更新后的速度；真正落地才结束空中动作，箱子破碎后重获支撑不会强行中断射击。
- 最后一发耗尽时，先选旧武器的待机动画，再退回默认手枪；传送镜头内部重绘仍推进原视觉状态，结束时处理排队输入。
- 竖直平台及终端会写入特殊脚下网格行，直到下一次纵向更新；跳跃顶点通过水平移动贴上台阶后，仍执行原本已经进入的重力步骤。
- 生成器参数与物件分离；37 型生成器销毁后，后续生成器会使用前一参数槽。爆破当步仍计入清场判断，提示下一步才出现，均保留原遍历语义。

## 验证尚未覆盖

前两关已有各自独立的完整正常操作回放。八关加载、敌人/机关、关卡衔接和原版样本有自动测试，但其余六关仍需完整实玩。参考截图通过 Java2D 适配原字节码生成，未取得原机录像；没有把局部零差异扩大成整游戏逐帧 1:1 的结论。

确定性参考时钟按逻辑阶段前进，提示阅读等待和镜头展示等待不额外推进战斗时钟。这与真实手机在阻塞等待期间继续流逝的墙钟不完全相同；现有对照结论明确以此时钟适配为前提。
