## 🇺🇸 English Version

A Windows remake of NET Lizard's Java ME game Alien Shooter.

### Run

Open `bin/Release/AlienShooter.exe`. Keep the `assets/` folder and DLLs next to it.

### Build

Requires Visual Studio 2022/2026.

```bat
build.bat
build.bat Debug
build.bat Release run
```

You can also open `AlienShooter.sln` directly.

### Controls

Default keys

| Key | Action |
| --- | --- |
| A / D | Move |
| W | Jump |
| S | Crouch / Enter terminal |
| Left mouse / J | Fire |
| 1–4 | Select weapon |
| 5 | Pistol |
| Q / E | Switch weapon |
| Esc | Pause |

### Config

Edit `config.cfg` next to the exe, then restart the game.

| Key | Default | Description |
| --- | --- | --- |
| `Scalar` | `4` | Window scale; reduced automatically if the screen is too small |
| `MaxFps` | `120` | Frame rate limit |
| `ModernControls` | `1` | Modern control tweaks; `0` for original |
| `FallProtect` | `1` | Fall damage protection; `0` for original |
| `FireKey` | `j` | Fire key |
| `JumpKey` | `w` | Jump key; use `spacebar` for space |

### Save

Saves and logs are in `save/` next to the exe.

### Cheat

Type `chgod` in game: invincibility, all weapons, full ammo. Type it again to turn it off.

### Assets

Most of the raw pngs are encrypted or packaged and require preprocessing.

`assets/` is generated by the asset pipeline, see [tools/README.md](tools/README.md).

### Copyright

Original game assets belong to NET Lizard. Third-party licenses are in `src/3rdparty/`.

## 🇨🇳 中文版

NET Lizard 的 Java ME 游戏 Alien Shooter 的 Windows 重制版

### 运行

打开 `bin/Release/AlienShooter.exe`。保留同目录的 `assets/` 和 DLL。

### 构建

需要 Visual Studio 2022/2026。

```bat
build.bat
build.bat Debug
build.bat Release run
```

也可以直接打开 `AlienShooter.sln`。

### 操作

默认键位

| 按键 | 动作 |
| --- | --- |
| A / D | 移动 |
| W | 跳跃 |
| S | 蹲下 / 进入终端 |
| 鼠标左键 / J | 开火 |
| 1–4 | 选择武器 |
| 5 | 手枪 |
| Q / E | 切换武器 |
| Esc | 暂停 |

### 配置

修改 exe 旁的 `config.cfg`，重启生效。

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `Scalar` | `4` | 窗口倍率，屏幕放不下时自动缩小 |
| `MaxFps` | `120` | 帧率上限 |
| `ModernControls` | `1` | 手感优化，`0` 为原版 |
| `FallProtect` | `1` | 跌落保护，`0` 为原版 |
| `FireKey` | `j` | 开火键 |
| `JumpKey` | `w` | 跳跃键，空格写 `spacebar` |

### 存档

存档和日志在 exe 旁的 `save/`。

### 秘籍

游戏中输入 `chgod`：无敌、全部武器、满弹药。再输入一次关闭。

### 素材

原素材大多有加密，需要进行预处理。

`assets/` 由素材流水线生成，见 [tools/README.md](tools/README.md)。

### 版权声明

原游戏素材归 NET Lizard 所有。第三方库许可见 `src/3rdparty/`。
